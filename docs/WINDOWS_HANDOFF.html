SnapFlow 交付说明

把截图整理成能核对、能执行的事项。适合当前阶段的项目演示和小范围试用。

授权文件夹自动识别与分类核对标题与时间手动同步飞书

你已经在用这台电脑

继续打开已经跑通的原安装目录中的 start-windows.cmd，保留后台窗口。

这个 ZIP 用于交付和留存；现有配置、记录与文件夹授权继续保留在原安装目录。

当前交付不覆盖 Windows 上的现有程序或个人数据。

接收方是另一台电脑

需要 Windows、已安装的 Python 3.10+、可访问的图片识别 API 和使用者自己的飞书授权。

这是 Python 启动版，尚未制作独立 EXE 安装器。交付包不包含任何真实凭据。

第一次打开 · 四步

  1. 右键 ZIP，选择全部解压缩，放到独立文件夹。不要在 ZIP 预览窗口中启动。
  2. 在解压出来的文件夹内双击 start-windows.cmd，等待浏览器自动打开。以启动窗口显示的地址为准。
  3. 在“设置与连接 → 识别服务”配置可访问的 API 地址、密钥和模型；当前项目使用 gemini-3.8-flash 网关路由。新电脑须单独确认网络和调用权限。
  4. 选择截图文件夹并授权。新截图进入文件夹后，等待自动整理；飞书接入按包内 FEISHU_SETUP.md 操作。

通过已有 SSH 转接访问网关时，需要相应连接、Tailscale 和开发机在线。交付 ZIP 不提供这些账号或网络配置。

三分钟演示 · 用现有可用电脑

步骤操作与观察
1 · 放入截图将一张未处理过、日期和内容清楚的活动或任务截图放入已授权文件夹。
2 · 展示结果等待事项出现，打开卡片，核对分类、标题、日期时间和原图。需要核对的条目先补全再保存。
3 · 手动确认点击“同步飞书”，在确认框核对目标日历或任务账号，再确认。
4 · 飞书核对日程到所选日历对应日期查看；任务、待办和作业到飞书任务查看，核对标题与时间。

“三分钟”是演示安排，不是识别响应时间承诺；实际耗时取决于网络和模型。

飞书采用手动确认

保持设置页的两个“将之后整理好的……自动同步”选项关闭。若之前开启过，取消勾选并点击“确认同步授权”保存。

新安装默认关闭自动同步。每条记录由你点击“同步飞书”并确认后创建；灵感和资料保存在本地。应用仅单向创建，本地编辑或完成状态不会回写飞书。

已验证与试用边界

用户已确认 新截图自动出现整理结果、首条飞书手动同步成功。

批量持续处理、不同截图的分类准确率、Windows 重启恢复、任务和日程两类完整验收仍待补测。现有离线回归有 116 项后端检查及 12 组浏览器检查；本次交付只整理说明与打包，运行代码保持原样。

  • 支持 PNG/JPG/JPEG/WebP；单张最多 8 MB，手动批量选择最多 30 张，只监测授权文件夹当前层。
  • 原图留在原处。关闭网页后后台仍可运行；关闭后台、关机或休眠后停止处理。
  • 分享此干净 ZIP 即可；个人 data/、.snapflow-config/ 和私有凭据留在使用者本机。

遇到问题

打不开：先确认已全部解压、Python 已安装，复制启动窗口的错误文字。

无法识别：在设置里检测识别服务；新电脑不能沿用另一台电脑的网络可用结论。

同步后没看到：先看是否显示成功，再核对类别、目标日历和日期；结果不确定时先在飞书核对。
