SnapFlow Windows 截图助手

1. 将整个文件夹解压到 D:\CodeProgram\AgentM 下，先关闭旧版本的后台窗口。
2. 双击 start-windows.cmd，页面会自动打开。
3. 点击“授权截图文件夹”，在页面内选择磁盘并进入截图文件夹，再点“授权并开始”。

以后新截图自动整理，不用逐张上传或填写。
关闭网页后后台继续运行；关闭 Python 后台窗口或关机后停止。
已有 api_key.json 放在程序目录或其上一级会自动读取，也会查找同一项目中的旧版本配置。
成功读取后，私有配置保存在项目的 .snapflow-config 中，请保留该目录。
如提示未连接识别服务，进入“设置与连接”配置。
飞书需要先配置应用，再登录授权、选择日历并连接自己的任务。
原图不修改、不删除；旧版本数据不覆盖。

本版为 Python Windows 桌面启动版，要求电脑已安装 Python 3.10+。
更多说明见 README.md；验证记录在 verification 文件夹。

文件夹列表直接显示在页面中，不依赖外部 Windows 窗口。
后台每 3 秒检查新增或修改的截图，文件写入稳定后自动处理。
未连接识别服务也能先保存文件夹，配置完成后才开始识别。
