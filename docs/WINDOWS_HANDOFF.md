# SnapFlow · Windows 试用版

自动识别截图、分类并整理到本地；核对内容后，手动确认同步到飞书任务或日历。

**先打开同目录的 `先看这里.html`，可查看完整使用与演示说明。**

## 已经跑通的现有电脑

继续从原安装目录双击 `start-windows.cmd`，保留后台窗口。交付 ZIP 用于分享和留存，不需要覆盖原目录；配置与个人记录仍在原安装目录中。

## 新电脑首次使用

1. 安装 Python 3.10 或更新版本；程序本身无需额外 Python 包。
2. 右键 ZIP → 全部解压缩，放在独立文件夹。不要在 ZIP 预览窗口里启动。
3. 双击 `start-windows.cmd`，等待浏览器打开，以窗口中的实际地址为准。
4. 在“设置与连接”配置新电脑能访问的识别 API。项目使用的网关模型路由为 `gemini-3.8-flash`，需要有效调用权限。
5. 选择截图文件夹并授权；新截图会自动整理。
6. 飞书接入见 `FEISHU_SETUP.md`，权限导入文件为 `Feishu-Permissions.json`。使用者须完成自己的账号授权。

交付包不携带真实密钥、用户截图或账号登录状态。经由已有 SSH 转接访问网关时，还依赖对应连接、Tailscale 和开发机在线；新电脑需要单独配置和验证。

## 手动同步与三分钟演示

保持两个自动同步选项关闭；新安装默认关闭。如果之前开启过，取消勾选并点击“确认同步授权”保存。

1. 向已授权文件夹放入一张未处理过、内容和日期明确的截图。
2. 等待结果出现，打开卡片核对分类、标题、日期和原图，需要核对的事项先编辑保存。
3. 点击“同步飞书”，核对确认框的目标后确认。
4. 日程到所选日历的对应日期查看；任务、待办和作业到飞书任务查看。

演示时长取决于模型和网络。同步是单向创建，本地编辑和完成状态不会回写飞书；灵感与资料保存在本地。

## 试用边界

- 当前是 Python 启动版，尚未打包为独立 EXE 安装器。
- 用户已确认新截图自动出现结果及首条飞书手动同步成功。任务和日程两类完整验收、批量持续处理、日期与分类准确率、去重和 Windows 重启恢复仍待补测。
- 支持 PNG/JPG/JPEG/WebP，单张最多 8 MB；手动选择最多 30 张；只监测授权文件夹当前层。
- 原图保留。关闭网页后后台仍可处理；关闭后台、休眠或关机后停止。
- 分享干净 ZIP，个人 `data/`、`.snapflow-config/` 和凭据文件保留在使用者本机。

启动异常请复制启动窗口错误文字；识别异常在设置里检测连接；同步结果不确定时，先到飞书核对再决定是否重试。

内部运行版本：`windows-networkfix-20260916`。本次只整理交付说明与打包，运行代码未改动；原有 116 项离线检查及 12 组浏览器检查是历史验证记录，不代替新电脑实际使用验收。

源码与进度：[Ethan-Li-k/AgentM](https://github.com/Ethan-Li-k/AgentM)。包内 `MANIFEST.json` 包含逐文件 SHA-256，外部 `.sha256` 文件记录整个 ZIP 的校验值。
