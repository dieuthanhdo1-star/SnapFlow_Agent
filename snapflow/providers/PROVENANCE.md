# 网关适配器来源

`vlm_client.py` 原样取自 AgentM 项目的 `tools/vlm_client.py`（2026-09-09）。采用随应用发布的副本，使 Windows 解压版本无需依赖其他代码目录；未改动原调用器或密钥。

当前应用默认请求 `gemini-3.8-flash`，已保存的自定义模型配置优先。它是网关路由名，不是原厂身份认证，也不是跨厂商能力排名。网关可能自动回退；应用不自行发起第二次调用来重试或换路由。

`api_key.json` 只能留在用户自己的机器，不包含在交付包中。明确指定的 `VISION_GATEWAY_CONFIG` 优先；否则可读取程序目录、父目录、同一项目中的已识别旧版安装目录和 `.snapflow-config/` 中的配置。支持多套一层的 ZIP 解压目录。成功读取后在项目 `.snapflow-config/` 中保留私有副本，避免配置随版本目录一起移除；不扫描相册、下载目录或其他应用。旧版有不同账号配置时，要求在设置中明确选择，不擅自切换。
